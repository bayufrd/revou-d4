# Product Context

## App Name

Expense & Budget Visualizer

## Goal

Help users record daily expenses, review recent transactions, and understand spending distribution by category.

## Core Features

- Add transaction with item name, amount, category, and date
- Delete transaction
- Persist transactions in Local Storage
- Show total spending summary
- Show pie chart by category
- Support custom categories
- Support sort options
- Support spending limit highlighting
- Support dark and light themes

## Primary User Flow

1. Open the app in a browser
2. Add one or more expense transactions
3. Review the updated list and total
4. Inspect category distribution in the chart
5. Refresh the page and continue from saved data

## UX Expectations

- Fast load with no build step
- Clear form validation
- Mobile-friendly layout
- Readable list and chart presentation
- Simple GitHub Pages deployment
