# Prompt: Release Checklist

Before publishing or submitting this project:

- verify [`index.html`](../../index.html) loads without build tooling
- verify add/delete/persist flows in the browser
- verify chart renders after data changes
- verify custom categories still work
- verify theme preference persists
- verify repository includes [`.kiro/`](../)
- verify GitHub Pages settings point to the correct branch/root
- verify submission links are ready
