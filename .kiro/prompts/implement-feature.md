# Prompt: Implement Feature

Use this prompt when adding or extending functionality in this repository.

## Instructions

1. Read [`.kiro/agent.md`](../agent.md).
2. Review [`.kiro/context/product.md`](../context/product.md) and [`.kiro/context/architecture.md`](../context/architecture.md).
3. Inspect the current implementation in [`index.html`](../../index.html), [`css/style.css`](../../css/style.css), and [`js/script.js`](../../js/script.js).
4. Implement the smallest viable change.
5. Keep Local Storage behavior stable.
6. Confirm manual acceptance items from [`.kiro/specs/expense-budget-visualizer.md`](../specs/expense-budget-visualizer.md).

## Output Expectations

- concise plan
- minimal diff
- note any manual verification needed
