# Prompt: Review Change

Use this prompt when reviewing modifications before commit.

## Review Focus

- Does the change preserve the static-app architecture?
- Does it keep one CSS file and one JS file?
- Does it affect Local Storage keys or shape?
- Does it change transaction, chart, theme, or category behavior?
- Is the GitHub Pages deployment path still intact?

## Report Format

- scope reviewed
- risks found
- regressions to test manually
- final recommendation
