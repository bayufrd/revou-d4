# Workflow: Shipping

## Goal

Prepare a safe, commit-ready update for this repository.

## Steps

1. Read [`.kiro/agent.md`](../agent.md).
2. Confirm requested change against [`.kiro/specs/expense-budget-visualizer.md`](../specs/expense-budget-visualizer.md).
3. Make the minimal implementation update.
4. Manually verify browser behavior from [`index.html`](../../index.html).
5. Review changed files for consistency.
6. Check git status before commit.
7. Write a concise commit message.

## Commit Message Pattern

```text
chore(kiro): add workspace metadata and agent guidance
```
